# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅        |

## Reporting a Vulnerability

Do **not** open a public issue for security problems. Use GitHub's private
vulnerability reporting (the "Report a vulnerability" button in the Security
tab of this repository) so we can fix it before it is disclosed.

If private reporting is not available for you, email the repository owner and
mark the subject `[security]`.
